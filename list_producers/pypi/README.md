# PyPI

[PyPI](https://pypi.org/) stores attestations that can be access through their API as `https://pypi.org/integrity/{PACKAGE}/{VERSION}/{ARTIFACT}/provenance`.

**References:** 

- <https://blog.pypi.org/posts/2024-11-14-pypi-now-supports-digital-attestations/>
- <https://blog.pypi.org/posts/2023-04-20-introducing-trusted-publishers/>
